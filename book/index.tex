\markboth{Preface}{Preface}

This book is a tidyverse-based re-implementation of the
\href{https://www.itl.nist.gov/div898/handbook/}{NIST/SEMATECH
e-Handbook of Statistical Methods}, originally published as a static
HTML handbook with worked examples in
\href{https://www.itl.nist.gov/div898/software/dataplot/}{Dataplot}.

Each chapter follows the structure of the original handbook, but the
worked examples are reproduced using R and the
\href{https://www.tidyverse.org/}{tidyverse} family of packages
(\texttt{dplyr}, \texttt{tidyr}, \texttt{ggplot2}, \texttt{purrr},
\texttt{broom}, and related extensions). Original datasets are retained
for reference and validation.

The source content for this migration lives in \texttt{handbook/} at the
root of this repository.
