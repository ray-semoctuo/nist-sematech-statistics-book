1.3.3.30. Youden Plot

Purpose:
Interlab comparisons 		Youden plots are a graphical technique for analyzing interlab data when each lab has made 2 runs on the same product or 1 run on 2 different products.
Sample Plot:

This plot shows:

  1. Not all labs are equivalent.
  2. Lab 4 is biased low.
  3. Lab 3 has within-lab variability problems.
  4. Lab 5 has an outlying run.
Importance
Questions The Youden plot can be used to answer the following questions.
  1. Are all labs equivalent?
  2. What labs have between-lab problems (reproducibility)?
  3. What labs have within-lab problems (repeatability)?
  4. What labs are outliers?
Input:
2 response variables Y1 and Y2 and 1 lab id variable LAB 		There are 2 response variables. These can be 2 runs of the same product or 1 run of 2 different products. In addition, there is lab id variable (this is typically coded as an integer from 1 to k where k is the number of labs). In summary, there are 3 columns of data of with the same number of rows.
Definition:
Response 1 versus response 2 coded by lab 		Youden plots are formed by:
  1. Verical axis: response variable 1 (i.e., run 1 or product 1 response value)
  2. Horizontal axis: response variable 2 (i.e., run 2 or product 2 response value)
In addition, the plot symbol is the lab id (typically an integer from 1 to k where k is the number of labs). Sometimes a 45 degree reference line is drawn. Ideally, a lab generating 2 runs of the same product should produce reasonably similar results. Departures from this reference line indicate inconsistency from the lab. If 2 different products are being tested, then a 45 degree line may not be appropriate. However, if the labs are consistent, the points should lie near some fitted straight line.
Stat Category:
Interlab Studies 		Youden plots are a specialized format for interlab studies.
Usage:
Light 		Youden plots are excellent for their intended purpose of analyzing interlab data when there are 2 runs (or 2 products). However, they do not have much use outside of this specialized purpose.
