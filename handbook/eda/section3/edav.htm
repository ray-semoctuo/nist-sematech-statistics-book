1.3.3.31. Weibull Plot

Purpose:
Graphical check to see if data come from a Weibull distribution 		The Weibull plot is a graphical technique for determining if a data set comes from a 2-parameter Weibull distribution (the location is assumed to be zero).

The Weibull plot has special scales that are designed so that if the data do in fact follow a Weibull distribution the points will be linear (or nearly linear). The least squares fit of this line yields estimates for the shape and scale parameters of the Weibull distribution.

Sample Plot:

This Weibull plot shows that:

  1. the assumption of a Weibull distribution is reasonable;
  2. tthe shape parameter is 33.32;
  3. the scale parameter is 5.28; and
  4. there are no significiant outliers.
Importance:
Check distributional assumptions 		Many statistical analyses, particularly in the field of reliability, make the assumption that the data follow a Weibull distribution. If the analysis assumes the data follows a Weibull distribution, it is important to verify this assumption and also to find good estimates for the Weibull distribution.
Questions
  1. Does the data follow a 2-parameter Weibull distribution?
  2. What is the best shpae parameter for the 2-parameter Weibull distribution?
  3. What is the best scale (= variation) parameter for the 2-parameter Weibull distribution?
Input:
1 Response variable Y 		There is response variable, Y, which typically contains failure times. In addition, there can optionally be a censoring variable. This variable is typically set to 1 if the item failed by the failure mode of interest and 0 of the failure mode is not of interest.
Definition:
Weibull cumulative probability versus log(ordered response) 		The Weibull plot is formed by:
  • Vertical axis: Weibull cumulative probability expressed as a percentage
  • Horizontal axis: Log of ordered response
The vertical scale is log(log(1-p)) where p=(i-0.3)/(n+4) and i is the rank of the observation. This scale is chosen in order to linearize the resulting plot for Weibull data.
Stat Category:
Reliability, distributional fitting 		Weibull plots are used extensively in reliability analysis. They can also be used anytime an assumption is made that data are distributed as a Weibull distribution or you are simply attempting to find an appropriate distribution to model a data set.
Usage:
Light to moderate 		Weibull plots are common in reliability analysis. They are seldom used outside of reliability applications.

The Weibull ppcc plot and Weibull probability plot provide the same information as the Weibull plot. We tend to recommend the ppcc and probability plot methods, but Weibull plots are widely accepted in the reliability field.

Reference Nelson, (1982) "Applied Life Data Analysis", Wiley.
