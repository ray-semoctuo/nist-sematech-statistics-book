Links to Statistical Software for Use with the Handbook
Statistical Software for Use with the Handbook Dataplot, a free, downloadable statistical package, is integrated with the Handbook on the NIST web site. Many parts of the Handbook feature case studies or short examples using Dataplot that can be run by the reader from links on the pages of the Handbook.
We would like a wide range of other statistical software to be integrated with the Handbook as well. If you would like to integrate your statistical software with the Handbook by illustrating the use of your software with Handbook examples please contact Will Guthrie or Alan Heckert at NIST. They will provide background on Handbook integration methods and linkages between the Handbook and your web site.
We are also happy to provide general links to other statistical packages to help readers find the software suitable for their purposes. However, NIST cannot and does not endorse the quality or appropriateness of any software or other commercial products that are identified on this page.

Links to Software Integrated with the Handbook
Integrated Software Links in this section are to web pages maintained by vendors of statistical software packages that have been tightly integrated with the content of the Handbook. Integration in this context means that the vendor has created web pages that would allow a user to duplicate the analyses of examples or case studies presented in the Handbook with the vendor's software. This information is intended to make it easier for readers to be able to use the statistical methods described in the Handbook with the software that they find most useful or convenient. Vendors who wish to present alternate analyses of the examples or case studies may include these alternatives instead, as long as the methods used are clearly explained and the web pages would allow the alternate analyses to be carried out with the vendor's software.
Software is listed alphabetically by product name.
Dataplot
"Dataplot® is a free, public-domain, multi-platform (Unix, Linux, PC-DOS, Windows NT, etc.) software system for scientific visualization, statistical analysis, and non-linear modeling. The target Dataplot user is the researcher and analyst engaged in the characterization, modeling, visualization, analysis, monitoring, and optimization of scientific and engineering processes."

STATGRAPHICS Plus
"This link is to a homepage that accesses case studies from the NIST/SEMATECH Handbook that have been reworked using STATGRAPHICS Plus. A downloadable StatFolio, data file, and StatGallery are provided fo each case study. These STATGRAPHICS files are provided via Statpoint.com, an on-line computing center maintained by STATGRAPHICS Plus."

statpoint.com
"This link is to a homepage that accesses case studies from the NIST/SEMATECH Handbook that have been reworked using Statpoint.com software. Statpoint.com is an on-line computing center maintained by STATGRAPHICS Plus. Statpoint.com analyses are shown under "Graphical Output and Interpretation" and "Quantitative Output and Interpretation" for each case study, and real-time computations using Java applets are accessible from the "Work This Example Yourself" link for each case study."

Non-Integrated Software Links in this section are to general statistical software packages. These packages may allow you to perform at least some of the analyses described in the Handbook. However, they have not been integrated with the Handbook as described above.

"Design-Ease® or Design-Expert® software makes it easy for you to perform statistical design of experiments (DOE). Use response surface methods to optimize your process or mixture. Display optimum performance with terrific 3D plots. Design-Expert is a comprehensive DOE tool with all of the features of Design-Ease, plus much more."
