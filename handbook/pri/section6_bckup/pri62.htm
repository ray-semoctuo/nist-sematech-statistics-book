Fractional factorial asher case study
This asher experiment measured gate oxide thickness and also particle counts A case study using JMP to analyze the data from a fractional factorial experiment is shown here. The data can be downloaded as an EXCEL spreadsheet if the reader wants to try another software package to do the same analysis. 

Description of Experiment

This experiment involved a semiconductor manufacturing tool called an asher.

An asher is a silicon wafer processing tool that is used to remove photoresist from the surface of silicon wafers. The ash process typically has the wafer loaded into an airtight chamber. A vacuum is applied and one or more gases are introduced into the chamber. A plasma is induced for a fixed amount of time and at a controlled temperature. The tool may have several chambers whereby a multistep process can be used. In the following experiment, a multistep single wafer ash tool was examined. Unless noted, processing conditions were held constant. Two of the steps were examined. For the first step, only processing time was varied (TIME2). For the second step, chamber temperature (TEMP), processing time (TIME3), and CF4 gas flow were all varied.  Note that although the amount of CF4 was varied, the total gas flow was held constant (i.e., the amount of all gases introduced into the chamber). Two output variables of interest were change in gate oxide thickness (DELTA) and number of particles on the wafer (PARTICLE).

While the original experiment had additional runs added that allowed an RSM analysis, this example will only utilize the subset of runs that form a fractional factorial design with 5 added center points.

Experimental Design

Rename the factors as follows: A = TIME2, B = TEMP, C = TIME3 and D = CF4. The experimental design we will analyze can be generated from the defining relationship A = BC 
(or I = ABC).

This is a Resolution 3 design, with A aliased or confounded with BC, B aliased with AC and C aliased with AB. All the 2-factor interactions involving D can be estimated. From an engineering point of view, this design makes sense if the 2-factor interactions involving CF4 are possible candidates for the model and all other interactions are believed to be non relevant.

Assume the goal of this fractional factorial asher experiment is explore how to keep DELTA thickness below 20 angstroms while minimizing the number of particles. The chosen design has 4 factors and 2 responses. It needed to be completed in 8 runs. Because of a repeatability concern, we added 5 center points to the design. Notice the center points are at run numbers 3, 7, 9, 11, and 13.

Step 2: Create the theoretical model

Recall from the fractional factorial section, the confounding pattern of the defining relation tells you which two factor interactions can go in the model. In this example, temp is confounded with the time2*time3 interaction, time3 is confounded with the time2*temp interaction, and time2 is confounded with the time3*temp interaction. Therefore the only 2 factor interactions that we can cleanly estimate are the two factor interactions involving cf4.

Step 3: Create the actual model from the data

Creating the model using software will provide a first look at the data, and allow us to diagnose the acceptibility of the model using residuals. Note: JMP (and most DOE software packages) requires you enter the model you want to analyze. So, if you are analyzing an experiment you did not design yourself and you do not know what model to fit, you have to work out the defining relationships and the aliasing structure to determine the correct starting model (JMP will help you uncover the design aliasing structure by providing a "singularity table" when you try to fit a full factorial model).

Since JMP output after fitting a model will be shown later in this example, will will proceed to an analysis if the model residuals.

Step 4: Test the model assumptions using residual graphs (adjust and simplify as needed)

The residual is the difference between the observed value and the predicted value. The section on assumptions states that we expect them to be normally and independently distributed with a mean of 0 and some constant variance.

If we create a histogram of the residuals, we see that they are clearly not normally distributed.
 


 
 
 


 
 

The residual versus run order graph shows us for the response DELTA, all of the center point runs have a positive residual and all of the factorial points have a negative residual.
 


 
 
 

For the PARTICLE residual versus run order, the negative residual values are all center point runs, but there are also 2 center point runs that had a positive residual.


 
 
 

Based on the residual graphs we should examine the lack of fit for the responses.


 

Step 4 continued: If there is Lack of Fit, try transforming the response data

For the response DELTA, there is significant lack of fit as noted by the large F Ratio value in the lack of fit table. This leads us to the need for a transformation. Most Design of Experiments software packages will allow you to easily check all the power transformations.
 
 


 
 
 
 

The Box-Cox Transformation graph above shows that the squared transform will provide a better fit of the data. Therefore, we will square each DELTA value and re-fit the model with the squared response.
 
 


 
 
 

The Box-Cox Transformation graph for PARTICLE articles shows that a log or reciprocal transform might be better than the untransformed data, however it is not significantly different from the untransformed data. Since the lack of fit was not significant on the PARTICLE data, we choose to not transform that response.

We will then refit the model with the squared response and examine the residual values again.

The residuals of the squared DELTA values do not appear to be normal.


 
 
 

The center point values are shown as larger squares on the graph. The residuals are not normally distributed even after a transformation. We should examine the lack of fit by plotting the residual values against the predicted values, and against each factor in the design.
 
 


 
 
 

The residual versus predicted graph shows the center points are the only value where there is any spread in the residual values. In fact, all of the factorial points have the exact same residual value. Examining the residual versus each factor shows the same result – the center points are different from the factorial points.
 


 
 
 
 


 
 


 

The residual versus run order graph does not show any specific trend or change over time. It shows the center points are different from the factorial points.

To evaluate what is happening with the response DELTA, frequently it helps to plot the raw data against the factors included in the experiment. When examining the graphs below, one notices that the variation in the center points is very small compared to the variation at the end points.


 
 


 

While this is not unusual in an experiment, it will cause the data analyst to trade-off some things. The experimental error is obtained only through the replicate runs. For this response the replicate runs are only the center points, and the variation is very small. We use the experimental error to make the decision about the significance of the model, the lack of fit, and the significance of the terms in the model.

Step 4 continued: Simplify the model

Examining the coefficients for the terms in the model for the raw data shows the 3 interactions and one of the main effects would fall out of the model based on an alpha value of 0.05.
 


 
 

Evaluating the same table for the squared DELTA response shows different terms would be removed based on an alpha value of 0.05.
 


 
 

Different analysts have different approaches for solving the problem from this point. Most people agree that if a transformation improves the fit, you should transform the response. Then you should make the decision of terms to remove from the model based on the transformed response. Based on that scenario, we would remove the time2*cf4 interaction term from the model.
 


 

A contour plot or contour profiler provides a visual of the response(s) with respect to changing factors. Some software packages allow you to overlay multiple responses on one contour plot. JMP allows you to do that using the contour profiler option. The below graph is the reduced model based on the transformation, but is using the raw response values rather than the squared response values.
 


 

The contour is drawn at a DELTA value of 20 – the upper limit for the response. The goal of the experiment was to have a DELTA value less than 20 and minimize particles.

Step 5: Answer the Questions in Your Experimental Objectives

Based on the goal of minimizing particles and keeping DELTA to less than 20, the best settings of the factors would be temp and cf4 at the high setting, and time2 and time3 at the low setting. This would be the recommended settings for a confirmation run.
