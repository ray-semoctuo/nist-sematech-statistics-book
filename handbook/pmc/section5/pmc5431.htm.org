<!-- begin paragraph -->
<TR>
<TD WIDTH=15% VALIGN=top>
<!-- Add marginal notes below -->
<I>
</I>
</TD>
<TD VALIGN=TOP WIDTH=85%>
<!-- Add main text below -->
<b><u>Case 1: One group.</u></b>

</TD>
</TR>
<!-- end paragraph -->

<!-- begin paragraph -->
<TR>
<TD WIDTH=15% VALIGN=top>
<!-- Add marginal notes below -->
<i>Testing whether one multivariate sample has a mean vector
consistent with the target</i>
</TD>
<TD VALIGN=TOP WIDTH=85%>
<!-- Add main text below -->
The <i>T</i><sup> 2</sup> statistic can be employed to test
<ul>
   <b>H<sub>0</sub>: m = m<sub>0</sub></b>
</ul>
against
<ul>
   <b>H<sub>0</sub>: m = m<sub>0</sub></b>
</ul>
Under H<sub>0</sub>:
<ul>
   <img align=absmiddle src="eqns/t0sq.gif"
        alt="T(0)**2 = n*(Xbar-m)*S**(-1)*(Xbar-m)">
</ul>
has a <img align=absmiddle src="eqns/t2p.gif" alt="T**2(p,n-1)">
distribution and
<ul>
<img align=absmiddle src="eqns/t2f0.gif"
alt="F(0) = T(0)**2*(n-p)/(p*(n-1)  is approximately F(alpha,p,n-p)">
</ul>
Under H<sub>a</sub>, <i>F</i><sub>0</sub> follows a non-central
<i>F</i>-distribution.
<!-- <img SRC="eqns/mvar13.gif" height=226 width=410> -->

</TD>
</TR>
<!-- end paragraph -->

<!-- begin paragraph -->
<TR>
<TD WIDTH=15% VALIGN=top>
<!-- Add marginal notes below -->
<I>
High value of F<sub>0</sub> indicates departure from H<sub>0</sub>
</I>
</TD>
<TD VALIGN=TOP WIDTH=85%>
<!-- Add main text below -->
A high value for <i>F</i><sub>0</sub> indicates substantial deviations
between the average and hypothesized target values, suggesting a
departure from <i>H</i><sub>0</sub>.  In order to perform a
hypothesis test at a given
<img align=absmiddle src="eqns/alpha.gif" alt="alpha">-level,
we select a critical value
<i>F</i><sup><img align=absmiddle src="eqns/alpha.gif" alt="alpha">
</sup><i><sub>p,n-p</sub></i> for <i>F</i><sub>0</sub>.

</TD>
</TR>
<!-- end paragraph -->

</I>
</TD>
