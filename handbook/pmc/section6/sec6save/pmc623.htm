Interpretation of Output The first section of the output identifies the model and shows the starting values for the fit. This output is primarily useful for verifying that the model and starting values were correctly entered.

The section labelled "ESTIMATES FROM LEAST SQUARES FIT" gives the parameter estimates, standard errors from the estimates, and 95% confidence limits for the parameters. A confidence interval that contains zero indicates that the parameter is not statistically significant and could probably be dropped from the model. In this case, the parameters for lags 1, 2, and 3 are all statistically significant.
